# Apple Wallet: как завести аккаунт и получить ключи

Кнопка «Добавить в Apple Wallet» на странице успеха скрыта, пока нечем
подписать пропуск: неподписанный файл iPhone всё равно отвергнет. Google
Wallet работает и ничего из этого не требует — речь только про Apple.

Что есть сейчас: ключ и Pass Type ID `pass.kz.imbir.sert` из исходников
подрядчика (Team `8P2AARWSYR`, CONNECTED HOME LTD.). **Сертификат истёк
23.02.2026**, и оформлен он не на «Имбирь». Перевыпустить его может только
владелец того аккаунта — поэтому заводим свой.

Итог, ради которого всё делается, — четыре файла и два идентификатора:

| Что | Куда попадёт |
|---|---|
| сертификат Pass Type ID (`.cer` → PEM) | `APPLE_WALLET_CERT` |
| приватный ключ к нему (PEM) | `APPLE_WALLET_KEY` |
| промежуточный сертификат Apple WWDR | `APPLE_WALLET_WWDR` |
| ключ пушей `AuthKey_XXXXXXXXXX.p8` | `APPLE_WALLET_APNS_KEY` |
| Key ID ключа пушей (10 знаков) | `APPLE_WALLET_APNS_KEY_ID` |
| Team ID (10 знаков) | `APPLE_WALLET_TEAM_ID` |

Первые три нужны, чтобы карта вообще выпускалась. Ключ пушей — чтобы баланс
на уже добавленной карте обновлялся сам после списания в Altegio. Без него
карта выпустится, но замрёт на сумме покупки.

---

## Шаг 1. Решить, на кого оформлять

**Организация (ТОО «Imbir Group»).** Правильный вариант: аккаунт и ключи
принадлежат компании, а не человеку, и не пропадут вместе с ним. Дороже во
времени: нужен номер **D-U-N-S** — бесплатный, но выдаётся от 5 дней до двух
недель, и данные в нём (название, адрес, телефон) должны совпадать с
регистрационными до буквы. Плюс Apple проверяет, что заявитель вправе
подписывать за компанию, и может позвонить.

**Частное лицо.** Быстрее — обычно 1–2 дня, D-U-N-S не нужен. Ключи при этом
оформлены на человека: если он уходит, аккаунт и продление уходят с ним. На
самом сертификате покупатель имени не видит, технически разницы нет.

Стоимость одинаковая: **99 $ в год**, оплата картой, Казахстан поддерживается.
Начинать D-U-N-S стоит сразу — это самая долгая часть, и она бесплатна:
<https://developer.apple.com/enroll/duns-lookup/>.

## Шаг 2. Apple ID

Отдельный Apple ID на почту компании (например, `spa@imbir.kz`), **не личный**.
Включить двухфакторную проверку — без неё в Developer не пускают. Телефон для
кодов — тот, к которому есть постоянный доступ у салона, а не у подрядчика.

## Шаг 3. Регистрация в Apple Developer Program

Проще всего с iPhone: приложение **Apple Developer** → Account → Enroll.
С компьютера — <https://developer.apple.com/programs/enroll/>.

Что спросят:
- тип (Organization / Individual) — по шагу 1;
- юридическое название **точно как в регистрации**, для ТОО — латиницей так
  же, как в D-U-N-S;
- адрес, телефон компании, сайт `imbir.kz`;
- для организации — подтверждение полномочий подписывать;
- оплата 99 $.

Дальше ожидание: частное лицо — обычно день-два, организация — от недели.
Ответ придёт письмом на тот же Apple ID.

## Шаг 4. Pass Type ID

`developer.apple.com/account` → **Certificates, Identifiers & Profiles** →
Identifiers → **+** → **Pass Type IDs** → Continue.

- Description: `Imbir gift certificate`
- Identifier: `pass.kz.imbir.sert`

Имя можно оставить прежним: оно уникально внутри команды, а команда у нас
теперь своя. Если Apple скажет, что занято, — берём `pass.kz.imbir.gift` и
сообщаем мне: это одна строка в настройках.

## Шаг 5. Сертификат подписи

Здесь обычно застревают, потому что инструкция Apple предполагает Mac
(Keychain Access → Certificate Assistant). **Mac не нужен** — запрос на
сертификат (CSR) сделаю я, у нас для этого уже есть openssl:

1. Запрос уже готов — `secrets/imbir-wallet-new.csr` (создан 2026-09-01).
   Приватный ключ к нему `secrets/imbir-wallet-new.key` остаётся у нас и
   никуда не уезжает: без него сертификат бесполезен, и второй раз его не
   получить. Папка `secrets/` в `.gitignore`.
2. В кабинете: Identifiers → `pass.kz.imbir.sert` → Create Certificate →
   загрузить `.csr` → Continue → **Download** — придёт файл `pass.cer`.
3. Файл `pass.cer` присылаете мне. Он не секретный, но и публиковать незачем.

Сертификат действует **год**. За месяц до конца перевыпускается тем же
порядком — заранее поставьте напоминание, иначе кнопка тихо исчезнет.

## Шаг 6. Ключ для пушей (обновление баланса)

`developer.apple.com/account` → **Keys** → **+**:

- Key Name: `Imbir Wallet APNs`
- отметить **Apple Push Notification service (APNs)** → Continue → Register
- **Download** — файл `AuthKey_XXXXXXXXXX.p8`

Скачать можно **ровно один раз** — Apple второй копии не хранит. Сохраните
файл в менеджер паролей владельца и пришлите мне. Десять знаков в имени файла
— это Key ID, он тоже нужен.

## Шаг 7. Team ID

Membership details в том же кабинете, строка Team ID — десять знаков вроде
`8P2AARWSYR`. Пришлите вместе с остальным.

## Шаг 8. Что делаю я

Промежуточный сертификат WWDR скачиваю сам (он открытый:
<https://www.apple.com/certificateauthority/>), перевожу `.cer` в PEM,
раскладываю четыре файла на сервере вне репозитория, прописываю шесть
переменных и проверяю живьём: покупаю сертификат, добавляю карту на телефон,
списываю в Altegio и смотрю, что баланс на карте изменился сам.

## Если 99 $ платить сейчас не хочется

Альтернатива одна: попросить подрядчика (CONNECTED HOME LTD., их Team
`8P2AARWSYR`) перевыпустить сертификат на своём аккаунте и передать нам ключ.
Это быстрее и бесплатно, но карты салона остаются подписаны чужой командой,
и каждое ежегодное продление — снова через них. Google Wallet тем временем
работает, так что дожать Apple можно и позже: кнопка появится сама, как
только ключи окажутся на сервере.
