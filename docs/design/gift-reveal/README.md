# Экран «Вам подарок» — наработки дизайна

Архив прототипов, из которых выбирался экран открытия подарка на странице
сертификата (`/success`). Всё хранится здесь на случай, если захочется поменять
цвета или анимацию. Файлы самодостаточные: картинки и видео вшиты внутрь,
открываются двойным щелчком в браузере, интернет нужен только для шрифтов.

В серверный образ папка `docs` не попадает (`.dockerignore`), сайт от неё не
тяжелеет.

## Что выбрано (решение заказчика 2026-09-15)

- **Цвета коробки** — пять, выпадают случайно при покупке и закрепляются за
  сертификатом: №1 «Фирменный», №7 «Шампань», №11 «Мятный», №13 «Небесный»,
  №16 «Светло-серый жемчуг».
- **Анимация открытия** — B «Праздник».
- Закрытая коробка — вариант «Золотая линия на светлом» без переделок.

## Как поменять потом

- **Цвета.** На сайте в CSS заведены все 16 палитр (`app/globals.css`, блок
  `.gr[data-palette=…]`), а какие из них выпадают новым покупателям — задаёт
  один список в коде (`lib/gift-palettes.ts`, `GIFT_PALETTE_ROTATION`). Поменять
  набор — поправить этот список как угодно: дописать, убрать, переставить.
  Уже выданные сертификаты сохраняют свой цвет: он записан в базе при выпуске
  (`certificates.gift_palette`). У сертификата без записи цвет выбирается
  стабильно по его id (`resolveGiftPalette`) из отдельного списка
  `GIFT_PALETTE_FALLBACK` — его не трогать вовсе: индекс считается по модулю
  длины списка, и любая правка, даже дописывание в конец, перекрасила бы
  большинство таких коробок. Удалять палитру из CSS нельзя, пока в базе есть
  сертификаты этого цвета; что каждая палитра из кода есть в CSS, сверяет
  `tests/gift-palettes.test.ts`.
- **Анимация.** На сайте собрана только B (`components/gift-reveal.tsx`,
  классы `.gr-*`). Другую переносить из её прототипа здесь же: закрытая коробка
  у всех одинаковая, различается только то, что происходит после нажатия
  «Открыть подарок».

## Как это проверялось

- Закрытая коробка во всех цветах и во всех анимациях сравнивалась с исходной
  попиксельно — отличий ноль.
- Каждую анимацию после создания отдельно проверял придирчивый проверяющий:
  кадры каждые 100 мс, поиск пустых кадров, полупрозрачных «призраков»,
  рывков, наложений, горизонтальной прокрутки; найденное исправлено.
- Проверки делались в Chromium (Playwright). На живых iPhone и Android
  прототипы не смотрели.
