## Платежи

Вебхуков нет ни у одного провайдера — оплата подтверждается опросом либо
вручную из админки. Опрос страницы сначала смотрит статус заказа в нашей БД,
поэтому ручное подтверждение тоже доводит покупателя до `/success`.

| Способ | Состояние |
|---|---|
| Kaspi, выдача ссылки/QR | **работает** — ссылка на форму сервиса Kaspi собирается у нас |
| Kaspi, автоподтверждение | **нет источника** — API PayQR не отвечает (их сторона) |
| Оплата картой (ForteBank) | код готов и выверен по исходникам; **нет логина/пароля** |
| Halyk ePay | не начат — ждём реквизиты от банка |

Подробности реализации и что именно выверено живьём — в
[AGENTS.md](../AGENTS.md), раздел «Оплата».

**Тестовая покупка на 100 ₸** включается скриптом
`npx tsx scripts/apply-test-100.ts` (номинал + программа), выключается тем же
скриптом с аргументом `off`. Товар-сертификат на 100 ₸ заведён в Altegio
только на Мангилик и Тәуелсіздік.

- [ ] Связка с `lib/altegio/redemptions.ts` + кнопки в интерфейсе

**Сертификат подписи есть, но просрочен.** Из исходников заказчика извлечены
Pass Type ID `pass.kz.imbir.sert` (Team `8P2AARWSYR`) и приватный ключ — лежат
в `secrets/` (папка в `.gitignore`, см. `secrets/README.md`). Срок действия
истёк 23.02.2026, владелец — CONNECTED HOME LTD., не «Имбирь». Нужен
перевыпуск в Apple Developer.

**Важно про Apple:** карта обновляется только если в пропуске есть
`webServiceURL` и `authenticationToken`. У текущего сайта заказчика их нет —
там пропуск статический, баланс на нём замирает навсегда. Удалить карту из
кошелька программно нельзя: используем `voided`, карта сереет.

**Источник данных для баланса готов** — `lib/altegio/redemptions.ts` каждые
15 минут тянет остаток из CRM, в базе есть `balanceKzt` и статусы.

## Чем заблокировано

| Что | Чего ждём |
|---|---|
| Оплата картой | логин и пароль ForteBank (Basic). В экспорте Node-RED их нет — лежат в зашифрованном `flows_cred.json` на сервере заказчика |
| Автоподтверждение Kaspi | либо оживший API PayQR, либо ответ, как боевой сайт узнаёт об оплате (нужна вкладка Node-RED с `/pay/:orderId/kaspi` — в присланном экспорте её нет) |
| Halyk ePay | ClientID, ClientSecret, TerminalID от банка (`Epay@halykbank.kz`) |
| Apple Wallet | перевыпуск Pass Type ID сертификата (текущий просрочен) + APNs Auth Key |
| Google Wallet | проект Google Cloud, сервисный аккаунт, доступ к Wallet API |
| Замок на Cloudflare | переключить SSL/TLS домена с Flexible на Full (strict), потом запустить `deploy/lock-to-cloudflare.sh` |

Тестовые реквизиты Halyk просить не нужно — они публичные:
https://epayment.kz/docs/Test-credentials

## Требования Halyk, влияющие на код

- `invoiceId` — только цифры, 6–15 знаков, уникальность по последним 6 цифрам.
  У нас заказы с cuid, понадобится отдельный числовой счётчик.
- `postLink` обязателен — это наш URL, куда банк шлёт результат оплаты.
  То есть вебхук есть, в отличие от Kaspi и Forte.
